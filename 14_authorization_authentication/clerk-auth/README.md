# Clerk Auth Minimalist Demo

A simple, secure, and clean authentication demonstration built with **Next.js 15 (App Router)** and **Clerk**.

## Features

- **Minimalist Design**: A plain white theme focused on clarity and performance.
- **Clerk Authentication**: Seamless sign-in, sign-up, and user management using the latest Clerk SDK.
- **Next.js 15 Ready**: Built with React Server Components and modern web patterns.
- **Responsive**: Fully optimized for mobile and desktop viewing.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Framework**: Next.js 15
- **Auth**: Clerk
- **Styling**: Tailwind CSS
- **Design**: Minimalist White Theme

## UI Design

The interface has been intentionally simplified to follow a "Plain White" aesthetic, removing unnecessary gradients and patterns to focus on the core authentication experience.
